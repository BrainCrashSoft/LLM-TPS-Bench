# OpenAI-Compatible API Benchmark Tool

A PyQt6 desktop application for benchmarking any LLM served through an **OpenAI-compatible API**. Works with LM Studio, Ollama, vLLM, LiteLLM, and any other service exposing an OpenAI-style chat completions endpoint.

## Features

- **Universal compatibility**: Works with any OpenAI-compatible API (LM Studio, Ollama, vLLM, LiteLLM, local or remote servers)
- **Auto-discover models**: Automatically detects available models from the server
- **Configurable benchmarks**: Set max tokens, temperature, and number of runs
- **Custom prompts**: Use any prompt text for testing
- **Real-time results**: See per-run metrics as they happen
- **Summary table**: View all run results in a structured table
- **Average TPS calculation**: Automatically computes average tokens-per-second across all runs

## Screenshots

The application provides a clean GUI with:

## Requirements

### System Requirements
- **Python**: 3.8 or higher

- Any other OpenAI-compatible endpoint

## Installation

1. **Clone or download** this repository

2. **Install dependencies**:
```bash
pip install PyQt6 openai
```

3. **Start your API server**:

   **LM Studio**:
   - Open LM Studio, load a model
   - Start the local server (default: `http://localhost:1234/v1`)

   **Ollama**:
   ```bash
   ollama serve
   ```
   API endpoint: `http://localhost:11434/v1`

   **LiteLLM Proxy**:
   ```bash
   litellm --model huggingface/bigcode/starcoder
   ```

## Usage

1. **Launch the application**:
```bash
python bench_aui.py
```

2. **Configure connection**:
   - **Base URL**: Enter your API server address (default: `http://localhost:1234/v1`)
   - **API Key**: Enter your API key (default: `lm-studio`; for Ollama use any string like `ollama`, for OpenAI use `sk-...`)

3. **Select a model**:
   - Click "🔄 Refresh Models" to load available models from the server
   - Choose a model from the dropdown

4. **Set benchmark parameters**:
   - **Max Tokens**: Maximum tokens to generate per run (1-8192, default: 512)
   - **Temperature**: Sampling temperature (0.0-2.0, default: 0.0)
   - **Runs**: Number of benchmark iterations (1-50, default: 3)

5. **Enter a prompt** (optional): Customize the test prompt in the text editor

6. **Click "▶ Run Benchmark"** to start the benchmark

7. **Monitor results**:
   - Real-time output shows each run's performance
   - Summary table displays tokens, time, and TPS for each run
   - Average TPS is displayed at the bottom

8. **Click "⏹ Stop"** to cancel a running benchmark

## Understanding Results

- **Tokens**: Number of completion tokens generated by the model
- **Time (s)**: Wall-clock time taken for the completion
- **TPS**: Tokens Per Second - higher is better, measures generation speed
- **Average TPS**: Mean throughput across all benchmark runs
